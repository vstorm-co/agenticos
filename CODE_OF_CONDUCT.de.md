# Verhaltenskodex

[English](CODE_OF_CONDUCT.md) · [Polski](CODE_OF_CONDUCT.pl.md) · **Deutsch** · [Español](CODE_OF_CONDUCT.es.md)

## Die kurze Fassung

Seien Sie jemand, mit dem andere arbeiten wollen. Unterstellen Sie gute Absicht,
streiten Sie über den Code statt über die Person, und nehmen Sie die
Meinungsverschiedenheit ernst genug, um konkret zu werden.

## Was das hier heißt

**Erwartet:** technische Direktheit, ehrlicher Widerspruch, Fragen, die ohne
Entschuldigung gestellt werden, und die Bereitschaft, ohne Zeremonie „Ich habe
mich geirrt“ zu sagen.

**Nicht erwartet und nicht akzeptiert:** persönliche Angriffe, Belästigung,
jemanden abzutun statt seines Arguments, sexualisierte Sprache oder Bilder, die
Veröffentlichung privater Informationen anderer oder ein Verhaltensmuster, das
Menschen dazu bringt, mit dem Beitragen aufzuhören.

Direktheit ist willkommen. Verachtung nicht. Der Unterschied liegt darin, ob man
auf die Kritik hin handeln kann.

## Geltungsbereich

Das gilt im Repository, in Issues und Pull Requests und überall dort, wo jemand
das Projekt vertritt.

## Meldungen

E-Mail an **kacper.wlodarczyk@vstorm.co**. Meldungen werden von einem Maintainer
gelesen und vertraulich behandelt. Sie bekommen eine Antwort; wenn an der
Situation ein Maintainer beteiligt ist, sagen Sie es, und jemand anderes
übernimmt den Fall.

Maintainer können verwarnen, vorübergehend sperren oder dauerhaft ausschließen,
in dieser Reihenfolge oder auch nicht, je nachdem, was vorgefallen ist.
Durchsetzungsentscheidungen werden der betroffenen Person erklärt.

## Herkunft

Übernommen vom [Contributor Covenant](https://www.contributor-covenant.org),
Version 2.1, gekürzt auf die Teile, die wir tatsächlich anwenden werden.
