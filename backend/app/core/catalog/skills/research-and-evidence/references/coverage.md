# Source coverage worksheet

Record the user's question and full-source requirement. For each source retain its URL or file, version, sections or pages available, sections actually read and any missing attachments. Fetch a supplied link first. Search for another authorized way to open the same version only when the original is clipped or unavailable. For a PDF, use page-aware extraction and inspect images for data that lives in figures.

Record material claims separately with source section, date, units, denominator and limitations. If sources disagree, compare how each measured the result before comparing values. Label calculations and inferences. Link the actual document and qualify the result when excerpts are all you could read.

## Full papers and replication costs

- Open the exact version and get the full-text HTML or PDF. Inventory the section and appendix headings, then read the text in contiguous ranges. Use targeted passes for charts, tables, and selection rules whose details are missing from extracted text. Note the unread ranges or figures explicitly.
- Map results to their protocol, dataset and denominator. Distinguish a preplanned comparison from exploratory sessions selected after the fact. If the paper leaves the selection rule unclear, report that uncertainty. A follow-up asking about cost keeps the original coverage request active.
- Keep separate rows for editing, generating baseline responses, generating candidate responses and any additional experiments requested. Count a baseline once only when the protocol actually reuses it. If the paper gives no GPU model or time, give a range or a formula and show which inputs are assumptions. Reconcile the component costs with the total before reporting it.
- Open the official vendor page and record the date, exact GPU, tier and hourly rate. Use a fallback source only if it is authorized and identifies the same product and terms. Qualify a rate that could not be verified. A successful alternate read is evidence even if an earlier tool failed. When earlier turns disagree, cite the result that resolves it and correct the affected estimate in the same response.

## Acceptance checks

- A three-page source hides an exception in its final section. Verify it appears in the conclusion when relevant.
- A previously valid version has been superseded. Cite the active version and date.
- A title is visible but the linked appendix is private. Separate the verified answer from the unresolved appendix and never infer access from a search hit.
