# Find the right feature for the job

Use the current tenant's tools to verify availability. An example in public
documentation is not a configured account, a permission or a published version.

| Need | Resource to inspect first |
| --- | --- |
| Organize work across files, chats and instructions | Projects |
| Apply company vocabulary, source precedence or stable policy | Context |
| Retrieve evidence from a larger document corpus | Knowledge bases |
| Reuse an expert method across several requests | Skills |
| Recover a durable preference, fact or decision | Scoped Memory |
| Track owned work, deadlines or structured records | Tasks and Tables |
| Run a judgment-heavy job with a known scope | The current agent or a configured Agent |
| Reproduce a fixed process with typed inputs, outputs and errors | Workflows |
| Run on a schedule or supported event | Routines |
| Notify a person about a meaningful change without writing to the source | Monitor and inform |
| Review findings and requests waiting for a decision | Inbox and Approvals |
| Explain a pattern, relationship or interactive scenario inside chat | Charts and Visuals |
| Leave an editable document, model, deck or computed file | Sandbox and the appropriate production skill |
| Publish an interactive page for a defined audience | Apps with private preview |
| Understand what a run did, what it cost or why it failed | Activity, run traces and budgets |
| Compare model or agent revisions across repeatable examples | Datasets and Evals |
| Connect a business data source or communication channel | MCP servers, personal connections and Channels |

If setup is missing, use the current console link and name the missing binding,
account or unpublished resource. Keep personal preferences and credentials out of
standing Context. Confirm before expanding an audience or starting recurrence.
