# Summarising for a credit decision

A summary, not a recommendation. The decision has a named owner and it is not
this.

## The shape

Applicant and structure · what is being asked for and what for · income and how
it is evidenced · existing commitments · security offered, with valuation and
date · the three figures the policy tests turn on · anything in the file that
contradicts something else in the file.

## Contradictions get their own section

Income stated against income evidenced, turnover in the accounts against
turnover in the application, a director's other directorships not disclosed.
Report the two values and where each came from.

## Evidence quality

Say what is audited, what is management-prepared, and what is self-declared. A
number's provenance changes what it is worth.

## Never

Score, recommend, say the application is strong, or apply a policy threshold.
Present the figures the policy tests use and let the test be run by whoever
signs it.
