# Checking grant eligibility

This produces an assessment against published criteria. It does not award
anything.

## Work criterion by criterion

For each published criterion: met, not met, or cannot tell from what was
supplied — and for the third, exactly which evidence would settle it.

## Separate hard from assessed

**Hard criteria** are pass or fail: the deadline, the geography, the applicant
type. **Assessed criteria** are scored by a panel, and this never scores them —
it assembles the evidence the panel will read.

## Report

Hard criteria first with a clear pass or fail on each, then evidence gaps
ordered by whether they block. If a hard criterion fails, say so at the top: the
applicant is better served by knowing immediately.

## Always check

Deadline, duplicate applications from the same body, and whether the applicant
has an unacquitted prior grant.

## Never

Interpret a criterion, apply discretion, or advise how to phrase an application
to qualify.
