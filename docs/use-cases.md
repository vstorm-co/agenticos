# Choose a first task

Start with work whose result someone on the team can judge. These are documented starting points and proposed checks, not customer case studies or success-rate claims.

| Task | Input and output | Check and next step |
| --- | --- | --- |
| Answer a handbook question | A document and a question produce a source-backed answer | [Build the document agent](howto/first-document-agent.md), including the missing-policy question |
| Draft an equipment request | Supplied facts and a written procedure produce a handoff for review | Bind [knowledge and a skill](skills.md); check missing fields before adding any submission tool |
| Turn a CSV into a chart | A file and sandbox tools produce a calculation and output file | Configure the [sandbox](sandbox.md); compare totals with source rows and open the generated file |

The existing [screens and recordings](screens.md) show product interfaces. They are not evidence that your configuration passed these checks. Keep your input, actual output, run and errors together.

Choose one entry point through [channels](channels.md), then assign responsibility for [operation](rollout.md). If you are still selecting a platform, use the [comparisons](about/comparison.md).
