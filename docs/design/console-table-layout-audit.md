# Console table layout audit

Source review: 2026-11-21. This is a repository-only implementation ledger, not a claim of browser QA for every route. Root coordinates visual checks and CI. Scoped component tests cover the shared contracts and affected collection surfaces.

## Shared contract

Primary collections use the height supplied by the console, with `min-h-0` propagated through their page, tab and list frame. The table owns row scrolling and keeps column headers sticky; controls and the footer remain outside that scroll area. `DataTable.clientPagination` explicitly opts a complete in-memory collection into pages of 50, **after sorting the complete collection**. It is not enabled for offset/cursor APIs, infinite collections or partially loaded data. Page indices clamp when filtered data shrinks. Changing the page or client sort resets the table's scroll position.

`PaginationBar.showSinglePage` and `Pager.showSinglePage` retain discoverable, disabled previous/next controls at 1 / 1. A primary `DataTable` keeps this footer for an empty collection too; loading says Loading rather than claiming a count the request has not returned, and a read failure does not claim an empty collection. Existing embedded callers retain the previous optional-footer behavior.

## Raw table review

- **Organization roles** (`orgs/[id]/roles/page.tsx`): retained the existing bounded, focusable matrix scroll region, sticky column headers and sticky permission names. Paging permission rows would separate the comparison from its headings and break this matrix's purpose.
- **Eval arms** (`components/evals/arms-table.tsx`): retained the responsive comparison inside its analytics card; the finite arm set is not a primary collection.
- **Skill usage** (`components/skills/skill-usage.tsx`): retained the aggregate beside its trend and other skill panels; hidden agents remain represented by the existing count.
- **Retention policy** (`components/orgs/retention-table.tsx`): retained seven configuration rows and responsive input layout; pagination would hide policy fields in one form.
- **Queue job activity**, dashboard **version comparison / top organizations / top people**, and workflow **statistics**: retained finite aggregate sections in their existing dashboard/detail composition.
- **Authoring diff**, **line diff**, chat **coding changes** and **Markdown tables**, workflow **node data view**, and **file CSV preview**: retained bounded/horizontal content viewers. These are embedded results, not collection pages; no unrelated full-height or paging behavior was added.
- **API reference field tables**, improvement **criteria**, onboarding **task result tables**: retained semantic embedded reference/form/demo content.

## Verification boundaries

Shared regression tests exercise sorting the complete collection before paging, page boundaries, synchronous clamping after filtering, a zero-record primary footer, and unchanged unpaged embedded behavior. A sandbox connection regression verifies that a row action on page two still targets the correct host. Existing scoped tests cover secret/account authority, sandbox sessions, commands, integration errors, server workflow histories/logs, API keys, connected clients, eval panels, dataset cases and skill bindings. Exact run counts are reported to the coordinating agent after the final scoped checks; no full local suite or browser automation was run by this worker.
