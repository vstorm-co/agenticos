# Product messaging

Primary reader: a technical team owner or integrator with a repeated document or tool-based task and an operating owner for a self-hosted deployment. Domain experts maintain the method; colleagues use the published agent.

Required Vstorm category label: **Sovereign Agentic AI Layer**. Keep this exact wording in the README hero in every language. Explain sovereignty as control over deployment, provider choices, configured data flows and access, not automatic offline execution.

Promise: **AI agents your whole team can use and improve.** Explain it with: configure shared agents in the browser, connect documents and tools, and publish them for colleagues. Engineers extend capabilities; domain experts maintain instructions and knowledge.

Lead with a task and a checkable result. Use the equipment-policy tutorial as the first substantive task, including a missing-answer check and a document update. A prompt-only task can check the installation but does not demonstrate team adoption. Explain the platform and OS architecture after the reader understands the work. Distinguish documented capabilities from executed demonstrations and proposals.

Show the file-and-command workflow with an execution-capable sandbox and an existing chat result. Explain how reusable skills, company context, searchable collections, apps and the customizable dashboard support that work. Distinguish roles from department groups and explain configured OIDC, LDAP and Kerberos sign-in. Use the Claude Code/Codex comparison for the workflow, without promising feature parity.

The OSS Launch Planner recording is an integration example using Vstorm projects, not customer evidence. Keep its caption faithful to the recording. Show selected views for configuring, sharing and inspecting work; link to the full feature documentation instead of reproducing its taxonomy.

Describe registry scale as MCP server listings, not tested integrations. Compare the nearest adoption decisions and acknowledge deployment ownership. Do not imply that another product lacks team features merely because its primary audience differs.

Never imply self-hosted means fully offline, zero budget overshoot, universal approval coverage or inherited source ACLs. Do not borrow client outcomes from unrelated Vstorm projects. Vstorm implementation and maintenance scope is agreed separately.

The primary campaign objective is AgenticOS recognition and adoption. Vstorm implementation and custom-project leads are a downstream benefit. Reuse the maintained comparison guides, operating page and help route rather than duplicating claims in campaign copy.
