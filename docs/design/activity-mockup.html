Design demo for issue #45 — not product code. Every number is fake. Each card names the endpoint that feeds it and the permission that reveals it; an amber badge means the endpoint or column does not exist yet. A control the caller may not use is absent — never greyed out, never a 403. Filters live on the tab that owns their column — Status is a runs column, so it narrows runs, not a global bar pretending to scope the queue and the spend too. Visibility is computed from a mirror of ROLE_PERMS, so member and viewer reach no version of this page at all: the sidebar entry gates on runs:view, which neither role holds.
