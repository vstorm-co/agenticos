The neutral card frames and text labels were added for the README. Each logo
has a light and a dark card variant; a white inset preserves the original mark
colors in both themes. manifest.json records the sources, dimensions and hashes.

Connection evidence:
- Google Drive: docs/howto/configure-sync-sources.md; gdrive connector.
- Gmail: docs/triggers.md; incoming-mail event trigger, not a sending tool.
- Outlook: third-party MintMCP email/calendar entries in the bundled
  backend/app/core/catalog/mcp_registry.json, also listed at
  https://www.mintmcp.com/servers . A separate provider account and permissions
  are required; no live Outlook account was connected for this README change.
- Notion, GitHub and Linear: backend/app/core/catalog/mcp_servers.json.
- Slack, Mattermost and Telegram: docs/channels.md.
