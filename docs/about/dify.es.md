# AgenticOS vs Dify { #agenticos-vs-dify }

El autoalojamiento y la recuperación documental son capacidades compartidas. Elige según cómo tu equipo construye, cambia y opera una tarea concreta.

Responsable: equipo de AgenticOS. Fuentes revisadas el 25 de septiembre de 2026. AgenticOS: v0.0.503. Dify: repositorio público y licencia, sin probar un plan de nube ni un despliegue fijado.

## Puntos de partida documentados { #documented-starting-points }

| Área | Dify | AgenticOS |
| --- | --- | --- |
| Construcción | Workflows visuales, agents y RAG | Instrucciones en navegador, herramientas, colecciones y versiones publicadas |
| Despliegue | Autoalojamiento Docker documentado | Despliegue gestionado por operador documentado |
| Licencia | Dify Open Source License con condiciones adicionales | Apache-2.0 para el proyecto; revisa aparte las licencias de componentes |

Consulta el [repositorio Dify](https://github.com/langgenius/dify), su [licencia](https://github.com/langgenius/dify/blob/main/LICENSE), la [guía AgenticOS](../first-agent.md) y el [inventario de licencias](../licenses.md). Autoalojado no implica las mismas licencias o funciones de edición.

## Compara un cambio, no solo una respuesta { #compare-a-change-not-only-an-answer }

Usa el mismo [manual sintético](../howto/first-document-agent.md), preguntas y criterios. Registra versión, modelo, procesamiento e identidad en ambos lados. Cambia el responsable de solicitudes y repite tras procesar la fuente.

Dify es candidato si los workflows visuales encajan con la forma de describir procesos del equipo. AgenticOS es candidato si encaja configurar y publicar agents con instrucciones, herramientas y colecciones. Comprueba las capacidades en la edición exacta que desplegarías.

No se presenta ejecución comparativa, clasificación de calidad ni tiempo de mantenimiento medido. Las incógnitas siguen abiertas. Usa el [método de comparación](comparison.md) y la [lista operativa](../rollout.md).
