# AgenticOS vs Wonderful { #agenticos-vs-wonderful }

Ein Enterprise-Kauf umfasst Bereitstellung und Betrieb rund um die Software. Wonderful präsentiert eine KI-Plattform mit Deployment-Teams. Ihr Team kann AgenticOS selbst betreiben; Implementierungshilfe von Vstorm wird separat vereinbart.

Verantwortlich: AgenticOS-Team bei Vstorm. Quellen geprüft am 25. September 2026. AgenticOS: v0.0.503. Wonderful: öffentliche AI-OS- und Deployment-Seiten, kein verhandelter Vertrag oder getestetes Konto.

## Den Lieferumfang bestimmen { #define-what-you-are-buying }

[Wonderful AI OS](https://www.wonderful.ai/ai-os) nennt Multi-Tenant-SaaS, Single-Tenant und Bring-your-own-Cloud. Das [Deployment-Angebot](https://www.wonderful.ai/deployment) beschreibt Umsetzungsteams. Prüfen Sie Verfügbarkeit und Bedingungen für Ihr Projekt. Eigene Infrastruktur allein ist deshalb kein Alleinstellungsmerkmal von AgenticOS.

Bei AgenticOS verantwortet der Betreiber die Bereitstellung. Vstorm kann Installation auf Kundeninfrastruktur, Dokumentation, Prozessgestaltung und individuelle Entwicklung unterstützen. Support, Wartung, Integrationen und Reaktionszusagen werden projektbezogen vereinbart und gehören nicht automatisch zum Repository.

## Fragen für die Liefervereinbarung { #questions-for-the-delivery-agreement }

| Bereich | Vor dem Pilot klären |
| --- | --- |
| Infrastruktur | Wo läuft jede Komponente, wer aktualisiert und stellt sie wieder her? |
| Daten und Zugriff | Welche Dienste erhalten Daten, wer pflegt Identitäten und Zugangsdaten? |
| Prozess | Wer definiert die Aufgabe, behandelt Ausnahmen und nimmt Ergebnisse ab? |
| Support | Wer bearbeitet Vorfälle mit welcher vereinbarten Abdeckung? |
| Ausstieg | Welchen Code, welche Konfiguration und Daten darf der Kunde behalten oder exportieren? |

Wählen Sie eine gelieferte Plattform, wenn Umfang und Verantwortung passen. Prüfen Sie AgenticOS mit Vstorm, wenn eigener Betrieb und individuelle Entwicklung passen. Keine Gleichwertigkeit von Enterprise-Funktionen, kein SLA und kein Kundenergebnis wird behauptet.

Definieren Sie eine prüfbare Aufgabe mit dem [Dokumentenbeispiel](../howto/first-document-agent.md) und [Betriebsleitfaden](../rollout.md). Kontaktieren Sie [Vstorm](https://vstorm.co/) oder Kacper für Implementierungshilfe. Vergleichen Sie Lieferumfang und [Softwarekriterien](comparison.md).
