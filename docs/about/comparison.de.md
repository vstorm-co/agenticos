## Ein gemeinsamer Versuch { #a-shared-trial }

Verwenden Sie das [Dokumentenbeispiel](../howto/first-document-agent.md) in beiden Produkten. Stellen Sie die beantwortbare Frage und die Frage zur fehlenden Regel. Ändern Sie die zuständige Person, verarbeiten Sie die Quelle erneut und wiederholen Sie den Versuch. Bewahren Sie Antworten, Konfiguration und Fehlschläge auf.

Erfassen Sie Version oder Tarif, Modell, Quellenverarbeitung, Identität, Werkzeugzugriff, Freigaben, Kanal, Kosten und Betriebsverantwortung. Beginnen Sie nur mit Retrieval. Falls eine Werkzeugaktion erforderlich ist, legen Sie zuvor eine harmlose Testaktion und die erwartete Freigabe fest.

## Was die Belege aussagen { #what-the-evidence-means }

Jeder Leitfaden nennt Quellen und Prüfdatum. Eine Herstellerbeschreibung belegt eine dokumentierte Option, nicht deren Qualität bei Ihrer Aufgabe. Für diese Leitfäden wurde kein Konto eines Mitbewerbers getestet. Ungeprüftes Verhalten bleibt unbekannt und wird nicht als fehlende Funktion markiert.

Nennen Sie bei veröffentlichten Versuchen genaue Eingaben, tatsächliche Ausgaben, Fehlschläge und Konfiguration. Trennen Sie Modellverbrauch von Infrastruktur, Implementierung und Betrieb. Prüfen Sie [Lizenzen](../licenses.md), Anbieterbedingungen und Edition.

## Weitere Ausgangspunkte { #other-starting-points }

Eine Bibliothek wie [Pydantic AI](https://ai.pydantic.dev/) passt zu einem Agent in Ihrer eigenen Anwendung. AgenticOS ergänzt eine Anwendung zum Konfigurieren und Betreiben. [n8n](https://n8n.io/) bietet Workflows und KI-Agents. [OpenClaw](https://github.com/openclaw/openclaw) dokumentiert persönliche und gemeinsame Team-Bereitstellungen. [Lindy](https://www.lindy.ai/) bietet einen Assistentendienst. Das sind weitere Kandidaten, keine ausgeschlossenen Produkte.

Beginnen Sie mit der [Dokumentenaufgabe](../howto/first-document-agent.md) und prüfen Sie dann [Betrieb und Implementierung](../rollout.md). Die AgenticOS-Maintainer betreuen diese Leitfäden. Quellen geprüft am 25. September 2026; nächste Prüfung bis 25. Oktober 2026 oder bei einer Angebotsänderung.
