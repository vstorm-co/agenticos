# Elige una primera tarea { #choose-a-first-task }

Empieza por un trabajo cuyo resultado pueda juzgar alguien del equipo. Cada tutorial de abajo te da una entrada sintética, la configuración, el prompt exacto, comprobaciones de referencia, los fallos habituales y qué registrar. Son puntos de partida con runs de referencia, no casos de clientes ni afirmaciones sobre tasas de éxito.

| Tarea | Entrada y salida | Tutorial | Última ejecución de los mantenedores |
| --- | --- | --- | --- |
| Responder una pregunta sobre el manual | Un documento y una pregunta producen una respuesta respaldada por la fuente | [Crea tu primer agent con documentos](howto/first-document-agent.md) | Aún sin registrar |
| Responderla en Slack | El mismo agent responde en un hilo de Slack, y el run muestra quién preguntó | [Responde una pregunta sobre el manual en Slack](howto/slack-handbook-assistant.md) | Aún sin registrar |
| Convertir un CSV en un gráfico | Un archivo y una sandbox producen totales, un gráfico, un script y un PNG | [Convierte un CSV en un gráfico que puedas comprobar](howto/csv-chart.md) | v0.0.504, 25 de septiembre de 2026 |
| Programar un informe semanal | Una tarea autocontenida produce un informe versionado según una programación | [Programa un informe semanal](howto/scheduled-report.md) | v0.0.504, 25 de septiembre de 2026 |
| Redactar una solicitud de equipo | Unos hechos aportados y un procedimiento escrito producen un traspaso para revisar | Vincula [knowledge y un skill](skills.md); comprueba los campos que faltan antes de añadir cualquier herramienta de envío | Aún sin tutorial |

Un run registrado muestra lo que hizo una configuración en una fecha, con un modelo. No prueba que tu configuración supere las mismas comprobaciones. El tutorial recoge los detalles. Conserva juntos tu propia entrada, la salida real, el run y los errores.

Las [pantallas y grabaciones](screens.md) existentes muestran interfaces del producto. Tampoco son una prueba de estas comprobaciones.

Elige un punto de acceso entre los [canales](channels.md) y después asigna la responsabilidad de la [operación](rollout.md). Si todavía estás eligiendo plataforma, usa las [comparaciones](about/comparison.md).
