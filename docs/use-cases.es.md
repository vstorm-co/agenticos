# Elige una primera tarea { #choose-a-first-task }

Empieza por trabajo cuyo resultado pueda evaluar alguien del equipo. Son puntos de partida documentados y pruebas propuestas, no casos de clientes ni tasas de éxito.

| Tarea | Entrada y salida | Comprobación y siguiente paso |
| --- | --- | --- |
| Responder sobre un manual | Documento y pregunta producen una respuesta basada en fuentes | [Crea el agent documental](howto/first-document-agent.md), incluida la política ausente |
| Redactar una solicitud | Hechos aportados y procedimiento producen un borrador para revisar | Vincula [knowledge y skill](skills.md); comprueba campos antes de añadir envío |
| Convertir CSV en gráfico | Archivo y sandbox producen cálculo y archivo de salida | Configura el [sandbox](sandbox.md); compara totales y abre el resultado |

Las [pantallas y grabaciones](screens.md) existentes muestran interfaces. No prueban que tu configuración haya superado estas comprobaciones. Conserva entrada, salida real, run y errores.

Elige un [canal](channels.md) y asigna la [operación](rollout.md). Para elegir plataforma, usa las [comparaciones](about/comparison.md).
