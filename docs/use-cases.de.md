# Eine erste Aufgabe wählen { #choose-a-first-task }

Beginnen Sie mit Arbeit, deren Ergebnis jemand im Team beurteilen kann. Jedes Tutorial unten liefert eine synthetische Eingabe, die Konfiguration, den genauen Prompt, Referenzprüfungen, die üblichen Fehler und das, was Sie festhalten sollten. Es sind Ausgangspunkte mit Referenz-Runs, keine Kundenfallstudien und keine Aussagen über Erfolgsquoten.

| Aufgabe | Eingabe und Ausgabe | Tutorial | Zuletzt von den Maintainern ausgeführt |
| --- | --- | --- | --- |
| Eine Handbuchfrage beantworten | Ein Dokument und eine Frage ergeben eine quellengestützte Antwort | [Den ersten Dokumenten-Agent bauen](howto/first-document-agent.md) | Noch nicht festgehalten |
| Sie in Slack beantworten | Derselbe Agent antwortet in einem Slack-Thread, und der Run zeigt, wer gefragt hat | [Eine Handbuchfrage in Slack beantworten](howto/slack-handbook-assistant.md) | Noch nicht festgehalten |
| Eine CSV in ein Diagramm umwandeln | Eine Datei und eine Sandbox ergeben Summen, ein Diagramm, ein Skript und ein PNG | [Eine CSV in ein prüfbares Diagramm umwandeln](howto/csv-chart.md) | v0.0.504, 25. September 2026 |
| Einen Wochenbericht planen | Eine in sich geschlossene Aufgabe erzeugt nach Zeitplan einen versionierten Bericht | [Einen Wochenbericht planen](howto/scheduled-report.md) | v0.0.504, 25. September 2026 |
| Einen Geräteantrag entwerfen | Gelieferte Fakten und ein schriftlicher Ablauf ergeben eine Übergabe zur Prüfung | [Knowledge und einen Skill](skills.md) binden; fehlende Felder prüfen, bevor Sie ein Werkzeug zum Einreichen hinzufügen | Noch kein Tutorial |

Ein festgehaltener Run zeigt, was eine Konfiguration an einem Datum mit einem Modell getan hat. Er belegt nicht, dass Ihre Konfiguration dieselben Prüfungen besteht. Das Tutorial enthält die Details. Bewahren Sie Ihre eigene Eingabe, die tatsächliche Ausgabe, den Run und die Fehler zusammen auf.

Die vorhandenen [Bildschirme und Aufnahmen](screens.md) zeigen die Produktoberflächen. Auch sie belegen diese Prüfungen nicht.

Wählen Sie über die [Kanäle](channels.md) einen Einstiegspunkt und weisen Sie dann die Verantwortung für den [Betrieb](rollout.md) zu. Wenn Sie noch eine Plattform auswählen, nutzen Sie die [Vergleiche](about/comparison.md).
